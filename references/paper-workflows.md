# 论文叙事的可执行工作流

本文件把六大范式变成四种常用交付模式。每种模式都先做证据账本和主张图，再选择相应产物；不要直接从“写摘要”开始。

## 模式 A：复盘一篇论文或一组获奖论文

**输入**：论文 PDF/链接/摘要、目标会议、用户希望理解的角度。

**步骤**：

1. 用自己的话写出论文解决的现象，而不是重复标题；
2. 找出作者挑战的默认设定、根因、理论对象或真实约束；
3. 将方法分成“必要机制”和“实现配件”；
4. 从图、表、定理和附录抽取“主张 → 证据 → 边界”；
5. 选择主范式和辅助范式，说明为何不是其他范式；
6. 把可迁移原则改写为用户项目中的可检验问题，不直接照搬方法。

**输出模板**：

```text
一句话主线：
主范式 / 辅助范式：
被解决的现象：
被推翻或补足的默认设定：
关键机制/测量/理论：
方法如何直接作用于它：
决定性证据（图/表/定理）：
不成立的边界：
可迁移的研究问题（不是可迁移的结论）：
```

如果没有原文，只能把结论标为“根据用户摘要的暂定解读”，不要补写未提供的实验或获奖理由。

## 模式 B：研究 idea 定位与“杀手实验”

**输入**：任务、已有观察/结果、数据和预算、目标 venue（可选）。

**步骤**：

1. 把 idea 改写成“现象—解释—干预—预测”；
2. 列出三个最接近的现有解释，并说明你的预测如何区分它们；
3. 选择主范式，删掉无法被当前证据支持的副叙事；
4. 设计最小决定性实验，而不是先设计完整系统；
5. 设计一个会让故事失败的结果，并写出失败后的转向；
6. 只有主张通过压力测试后，才决定需要哪些模块、数据和刷榜实验。

**输出模板**：

```text
研究现象（可复现）：
现有方法/解释的具体漏洞：
我们的核心假设：
主范式及选择理由：
C1（现象）：
C2（机制/理论/基准）：
C3（比较/影响）：
杀手实验：
关键对照与替代解释：
若失败，故事如何收缩或改写：
所需最小系统/数据/预算：
```

“杀手实验”应满足：结果有方向性、能区分至少两个解释、成本可接受、即使失败也能缩小问题，而不是只追求更高平均分。

## 模式 C：从论证图生成论文结构

### 标题

标题优先写现象、机制或重构动作；不要把“更强”“新颖”“SOTA”当作唯一信息。可用：

```text
[现象/矛盾]：通过 [机制/接口/测量] 的 [研究动作]
[机制] explains [现象] / [方法] for [任务]（只有原文确实支持时使用）
```

### 摘要五句骨架

1. **背景与缺口**：在什么任务/场景，现有做法看不到什么问题；
2. **关键发现**：我们观察或形式化了什么反常现象/根因；
3. **方法动作**：基于该发现做了哪一个直接干预、理论构造或测量设计；
4. **证据结果**：在最能区分故事的设置上得到什么结果，注明范围/成本；
5. **意义与边界**：改变了什么理解或流程，哪些情况仍未覆盖。

### 引言四段骨架

1. **现象**：用一个可验证失败或真实痛点开场；
2. **诊断**：展示默认解释为何不够，给出根因、反例、理论问题或测量缺口；
3. **动作**：说明方法/基准/定理如何直接对应诊断，并列可证伪预测；
4. **证据与贡献**：按主张顺序预告实验、理论、边界和可迁移价值。

Related Work 不要写成论文目录。按“别人采用的解释/设定 → 它们遗漏的现象 → 本文如何可区分”组织。

### 方法与实验顺序

每个方法小节先回答“它解决主张图中的哪一个节点”，每个实验小节先写“要区分哪些解释”。推荐实验顺序：

1. 诊断或理论预测；
2. 决定性干预/主比较；
3. 机制消融和反事实；
4. 分布、规模、噪声和资源边界；
5. 真实流程、跨群体或迁移；
6. 失败案例、限制与误用风险。

## 模式 D：审稿与 rebuttal

先读 [reviewer-stress-test.md](reviewer-stress-test.md)。输出应区分“观点分歧”“证据缺口”“写作不清”和“确实错误”，不要把所有低分都归结为审稿人没看懂。

**逐条回应模板**：

```text
Concern：用一句话准确复述质疑，不扩大或稻草化。
Answer：直接回答结论及适用范围。
Evidence：给出图/表/定理/附加实验或原文位置；没有证据就承认限制。
Change：说明修订了哪一段、哪张图、哪项实验或措辞。
Boundary：指出仍然不声称什么。
```

若审稿人质疑“方法有效但不新”，回到“问题/机制是否被重新定义、是否有新可证伪预测、是否降低了复杂度或暴露了新失效”；若质疑“故事好但证据不足”，优先补决定性对照和边界实验，而不是增加宣传性文字。

## 叙事修订循环

```text
删掉无法证实的句子
→ 合并重复主张
→ 给每条主张指定证据和反例
→ 按因果顺序重排图表与段落
→ 模拟 30 分钟初审
→ 在失败处降低措辞或补实验
```

一轮修改只解决一类问题：主线、机制、证据、可读性或边界。这样能判断分数/反馈变化来自哪里，也能避免为了回应一个意见继续堆模块。
