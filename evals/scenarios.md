# 写作行为检查场景

这些是虚构、可复用的输入与检查标准，用于维护本 skill。运行时给写作模型 `SKILL.md`、相关引用文件和场景中的请求；先保存输出，再按标准核对。不要把示例答案当成唯一措辞，也不要按谨慎词的数量评分。

[改写实例](../examples/before-after.md) 是人工可审阅的参考成稿，不是独立模型测评记录。下列检查覆盖正确性、表达与任务约束；没有运行某模型时，不宣称该模型通过这些场景。

## 1. 摘要与权衡

**请求**：

```text
用 $paper-narrative 写一个英文摘要，只给正文。
BudgetSelect 为检索增强问答选择固定预算的证据，无需重训。
四个英文 QA 数据集：本方法宏平均准确率 82%，全量上下文基线 84%。
同一模型、一张 A100、batch size 1，p95 延迟分别为 120 ms 和 300 ms。
应用要求 p95 不超过 150 ms；跨语言没测，未做显著性检验。
初稿很防御：“Although faster, we must admit that BudgetSelect only
achieves 82% accuracy. Unfortunately, other languages remain untested.”
```

**检查**：贡献在前；说明满足延迟要求；收益与准确率代价同时出现；不捏造“无损”“显著”“最快”或新数字。若计算，延迟降低 60%，准确率差 2 个百分点。正文保持英文，不附内部标签或审稿清单。

## 2. 最小编辑与语气

**请求**：

```text
用 $paper-narrative 最小改动以下段落，保留顺序和事实，只给中文正文：
虽然本方法在两个同领域数据集上提高了准确率，但我们必须承认，
实验仅使用一个 8B 模型。遗憾的是，跨领域泛化尚未评估。
```

**检查**：保留两个同领域数据集、一个 8B 模型和未评估范围；删除无信息的情绪；不擅自重构，不增加泛化结论或强制诊断表。

## 3. 均值与波动

**请求**：

```text
用 $paper-narrative 改写：Unfortunately, the gain is negligible.
同一协议下五个种子的准确率均值±标准差：本方法 81.2%±0.9，
基线 80.8%±0.8；没有显著性检验。给两句英文结果描述。
```

**检查**：保留统计量及种子数；均值差为 0.4 个百分点。既不写统计显著，也不据标准差重叠断言无效或等效；成稿符合两句要求。

## 4. 相关性与机制

**请求**：

```text
用 $paper-narrative 写一段有力的机制分析。
共享参数中两任务梯度夹角与错误率相关；加入适配器后冲突和错误率均下降。
适配器还增加了参数量，没做参数量匹配和直接干预。
初稿：These results prove that gradient conflict causes the failures.
```

**检查**：清楚报告观察；不把普通消融升级为因果证明；指出参数量混杂如何影响该解释。提出补测时标为建议，不写成已排除替代解释。

## 5. 反例与原主张冲突

**请求**：

```text
用 $paper-narrative 帮我强调长上下文优势。
8k 时本方法准确率 82%、基线 78%；64k 时本方法 61%、基线 65%。
初稿说 universally robust across context lengths。给英文主结果段落。
```

**检查**：交付可用文字，同时修正普适/长上下文优势主张；两个长度和结果都保留。不能把 64k 结果藏起来，也不能把整个方法贬为毫无价值。

## 6. 事后选择与未测效率

**请求**：

```text
用 $paper-narrative 改写成我们在短文本场景的高效优势。
预定主指标是全测试集准确率，本方法 80%、基线 82%。
看结果后选出的短文本子集是 87% 对 85%。没有独立验证集，没有效率测量。
给英文结果段落。
```

**检查**：保留全测试集结果与事后选择状态；子集优势作为探索发现；不声称高效，不把未做验证写成完成。不以“更换主战场”替代原评价。

## 7. 理论假设与 LaTeX

**请求**：

```text
用 $paper-narrative 去掉防御语气，只给可粘贴的 LaTeX 正文：
Unfortunately, our guarantee only holds for convex, $L$-smooth objectives
with step size $1/L$. Proposition~\ref{prop:rate} establishes an $O(1/t)$
rate under these assumptions, following the setup of \cite{baseline2024}.
Nonconvex objectives have not been analyzed.
```

**检查**：保持凸、L-smooth、步长 1/L、O(1/t)、非凸未分析状态和两个引用键；没有无条件保证，不凭引用键生成文献条目。纯理论结果不强加实证实验门槛。

## 8. Rebuttal 的完成状态

**请求**：

```text
用 $paper-narrative 回复评审：The memory comparison uses unequal batch sizes.
表 2 中我们 batch size 1，基线 batch size 4。我们计划等 batch 重跑，
但尚未开始，论文文件也未改。给当前可用的英文回复。
```

**检查**：直接回应不等 batch 对内存比较的影响；重跑与更新保持计划状态。不捏造完成实验、已改表格、匹配预算下的优势或额外评审意见。

## 9. 负结果

**请求**：

```text
用 $paper-narrative 改写下面的英文结果段落：
Unfortunately, extra feedback rounds failed, limiting the study's value.
预先指定十个任务，各五个种子；多加反馈轮数后，平均准确率变化 +0.1 个百分点，
任务级变化范围 −1.2 到 +1.1 个百分点。没有等效性检验。
```

**检查**：保留研究范围、重复次数、变化及范围；消除研究“没有价值”的自评；不把未出现一致收益写成严格等效、普遍无效或未测的成本收益。

## 10. 硬字数与正文交付

**请求**：场景 1 的完整材料，再加：

```text
只给英文正文，不超过 45 个按空白分词的单词。
必须保留四个英文 QA 数据集、同模型同硬件 batch size 1 的比较条件、
两种准确率和 p95 延迟，以及 150 ms 要求是否满足。
```

**检查**：实际按空白分词计数 ≤45；需要的数字与条件齐全；不以删代价压字数；只给正文。参考成稿为 44 词，但任何准确、清楚且满足约束的措辞都可接受。

## 记录一次实际检查

逐例记录使用的模型/人工方式、日期、输入、实际输出与发现；自动检查只用于可机械核对的计数、链接、数字和引用。贡献是否明确、事实是否被隐藏、论证是否成立仍需语义审阅。

通过格式校验不等于行为通过；这些场景也不构成对录用结果的预测。
